# Lab 1 Agentic Pipeline Report

This report documents the results of the text exploration and analysis pipeline performed on the 20-newsgroups dataset (covering four categories: alt.atheism, comp.graphics, sci.med, and soc.religion.christian, totaling 2,257 documents).

## 0. Tool Access Control and Permission Gate
Before executing custom pipeline tools, the agent enforced a strict workspace permission gate. When instructed to run `variance_filter_tool` directly without prior authorization, the agent correctly paused and requested tool access instead of assuming permission. An attempt to request and grant access in the same turn was appropriately refused by the agent in adherence to lab rules. Following a formal access request and explicit approval, all 13 custom tools were unlocked in a single batch. Subsequently, calling a previously unmentioned custom tool (`check_missing_tool`) executed immediately without requiring any new authorization requests.

## 1. Data Loading and Quality Check

2,257 documents were successfully loaded using load_dataset_tool (load_dataset_1). Subsequently, check_missing_tool (check_missing_2) and check_duplicates_tool (check_duplicates_3) were used to check and confirm that there were no missing text values (0 missing values) and no duplicate documents (0 duplicates). All 2,257 documents were successfully retained for subsequent feature extraction.

## 2. DTM Construction and Variance Filtering

A document-term frequency matrix (DTM) was built using build_dtm_tool (build_dtm_4). The matrix dimensions were [2257, 35788], with a sparsity of 99.547%, containing 35,788 unique words. Then, variance_filter_tool (variance_filter_5) was used for variance filtering with a threshold of 0.01, removing 30,434 low-variance words with near-constant frequency, retaining 5,354 words. Analysis revealed that high-frequency numbers or short strings such as '00' and '000' were retained because they appeared frequently in multiple documents with sufficient fluctuation in frequency, while extremely rare strings were successfully filtered out.

## 3. Category Relevance Filtering and Feature Visualization

To identify words highly correlated with the comp.graphics category, pearson_filter_tool (pearson_filter_6) was executed, retaining 3,418 features with |r| > 0.05 at a threshold of 0.05. Observing the results sorted by absolute correlation coefficient, the top-ranked positively correlated features included not only computer graphics terms such as vga, video, card, and algorithm, but also a large number of email headers and greetings (such as thanks, keywords, hi, nntp, and host); while the negatively correlated side showed common words in reply and quotation phrases such as re, writes, people, who, and that. This shows that without removing headers and stop words, the Pearson correlation coefficient actually captures the unique "posting and interaction style" of each newsgroup, rather than simply the topic words. ## 4. Dimension Reduction and Label Binarization
PCA dimensionality reduction is performed using reduce_dimensions_tool (reduce_pca_7), projecting the feature matrix into a 2D space. The first two principal components cumulatively explain approximately 70.27% of the variance (65.94% for the first principal component and 4.33% for the second principal component). However, the generated 2D scatter plot shows that, in the raw word frequencies without normalization or TF-IDF transformation, there is no clear separation among the four categories. The vast majority of documents are clustered near the origin, while a few long documents (extreme outliers) stretch the axis ranges, reflecting that the first principal component is likely driven by document length.

![PCA Scatter Plot](../plots/范祥彥_agentic-pipeline_plot_reduce_pca_7.png)

Finally, the text category labels are converted into a one-hot encoded binary matrix of shape [2257, 4] using binarize_labels_tool (binarize_labels_8), corresponding to the order ['alt.atheism', 'comp.graphics', 'sci.med', 'soc.religion.christian'], for subsequent model use.
